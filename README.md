# suho · 수학클래스룸

학원용 수학 웹앱입니다. 코드는 `web/` 폴더(Next.js)에 있고, 데이터는 Supabase(Postgres)에 저장하며 Vercel에 배포합니다.

- 웹앱 설명과 실행 방법: [`web/README.md`](web/README.md)
- DB 표 만들기 SQL: [`db/schema.sql`](db/schema.sql) (Supabase SQL 편집기에서 실행, 여러 번 실행해도 안전)

예전 Streamlit 앱(`app.py`)과 구글 Apps Script(`apps_script/`)는 2026-10-05에 웹앱으로 모두 옮겨서 지웠습니다. 필요하면 git 기록에서 되살릴 수 있습니다.
